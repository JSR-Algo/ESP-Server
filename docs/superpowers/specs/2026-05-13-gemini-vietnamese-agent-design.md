# Gemini Vietnamese Agent Design

## Goal

Configure the ESP32 server agent to use Gemini for chat responses and answer in Vietnamese by default.

## Scope

- Switch the selected LLM module to `GeminiLLM`.
- Keep Gemini API key configuration in `config.yaml`.
- Add a root-level `response_language: "Vietnamese"` setting.
- Update prompt rendering so `{{language}}` uses `response_language` first.
- Optionally switch TTS to `GeminiTTS` so spoken output is also generated by Gemini.

## Current Behavior

`config.yaml` currently selects `ChatGLMLLM` for LLM and `EdgeTTS` for TTS. The base prompt template already tells the model to reply in `{{language}}`, but `PromptManager` derives that value from the selected TTS module's `language` field and falls back to `Chinese`.

This couples response language to TTS configuration and makes Vietnamese behavior indirect.

## Proposed Behavior

Use a dedicated response-language config value:

```yaml
response_language: "Vietnamese"
```

`PromptManager.build_enhanced_prompt()` should resolve language in this order:

1. `config["response_language"]`
2. selected TTS module `language`
3. `"Chinese"` fallback

`selected_module.LLM` should be set to `GeminiLLM`. `GeminiLLM.api_key` must be filled by the deployer.

If Gemini voice output is desired, `selected_module.TTS` can be set to `GeminiTTS`, with Vietnamese style instructions.

## Configuration Shape

```yaml
selected_module:
  LLM: GeminiLLM
  TTS: GeminiTTS

response_language: "Vietnamese"

LLM:
  GeminiLLM:
    type: gemini
    api_key: your-gemini-api-key
    model_name: "gemini-2.0-flash"

TTS:
  GeminiTTS:
    type: gemini
    api_key: your-gemini-api-key
    model_name: "gemini-2.5-flash-preview-tts"
    voice: "Kore"
    style_instructions: "Nói tiếng Việt tự nhiên, rõ ràng, thân thiện."
```

## Error Handling

Existing provider initialization logs missing API keys through `check_model_key`. No new runtime error handling is required for the language prompt change.

## Testing

- Static check: confirm `PromptManager` builds prompts with `Vietnamese`.
- Config check: confirm selected LLM is `GeminiLLM`.
- Optional live test requires a valid Gemini API key and network access to Gemini.
